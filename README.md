# Gyeol

**A body-conformal personal computer that becomes a conventional smartphone when removed from the body.**

Gyeol is a LifeOS Studio R&D program exploring a daily-driver mobile computer that can transition between phone and forearm-worn forms while supporting local AI, world-facing perception, biometrics, cellular connectivity, and smart-home interaction.

This repository is the public research ledger. It publishes questions, baselines, benchmarks, experiments, failures, and reviewed results. Potentially patentable implementation details remain embargoed until an explicit IP decision is made.

## Program

- **Gyeol Armpad** — morphing smartphone / personal AI computer
- **Gyeol e-skin** — body-contact sensing and biometric interface
- **Gyeol Home** — local AI and smart-home edge infrastructure
- **Gyeol Research** — the research program that improves all of the above

## Research model

`main` must always describe a buildable system using validated technology. Research branches propose improvements. Moonshot branches may radically rebase the architecture, but are never prerequisites for the mainline product.

```text
idea -> hypothesis -> experiment -> evidence -> review -> merge | iterate | park | close
```

A result is not merged because it is interesting. It is merged when reproducible evidence shows that it improves the whole-system objective without unacceptable regressions.

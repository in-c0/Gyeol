# Benchmarks

Benchmarks make research branches comparable and prevent local optimizations from hiding whole-system regressions.

Initial benchmark families:

- mechanical rigidity / torsion / bend radius / fatigue
- ergonomic fit / pressure distribution / don-doff time
- daily-driver phone functionality
- perception energy per useful contextual event
- important-event recall and false wake rate
- wrapped/flat RF throughput, sensitivity, and link stability
- biometric signal availability under motion
- skin-side and outward thermal behavior
- usable energy / mass / volume / conformance
- interconnect fault injection and degraded-mode survivability
- lifecycle cost / repairability

Every benchmark gets a versioned protocol before it is used as a merge gate.

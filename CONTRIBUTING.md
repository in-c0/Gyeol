# Contributing

Gyeol welcomes criticism, replication, benchmark improvements, literature, experiments, and engineering proposals.

The preferred contribution is not "this would be cool." It is:

1. a falsifiable claim,
2. a baseline,
3. a measurable threshold,
4. an experiment capable of proving the claim wrong,
5. evidence.

Negative results are first-class contributions.

Do not submit confidential information, personal data, security-sensitive details, supplier-protected information, or potentially patentable enabling implementation without an explicit disclosure decision.
